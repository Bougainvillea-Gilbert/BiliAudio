能力说明：这个工具能做什么、不能做什么

✓ 能做

  • 主流视频站：B 站（BV / av / b23.tv 短链）、抖音、YouTube、X、Vimeo、微博视频等 yt-dlp 支持的 1800+ 站点。
  • 普通网页内嵌视频：文章页、博客里的 mp4 视频（如 Seed 官网的演示视频）会自动识别。
  • 多集内容：分 P、播放列表、一页多视频，逐集预览，支持勾选下载或合集下载。
  • 音频提取：MP3 / M4A / AAC，保留中文标题；视频下载：按清晰度选择（以片源实际提供的档位为准）。
  • 海外站：自动使用系统代理，也可手动填写代理地址。
  • 所有处理在本机完成，不上传任何数据到第三方服务器。

✗ 不能做 / 有限制

  • DRM 加密内容：爱优腾 VIP 剧集、Netflix 等加密流媒体无法解析（破解 DRM 属于违法行为，本工具不做）。
  • 需要登录 / 会员的内容：如 B 站大会员画质、仅粉丝可见视频，需要 Cookie 支持（当前版本未提供），只能拿到公开部分。
  • 纯 JS 动态加载的页面：如果网页 HTML 里没有视频标签、完全靠脚本运行时加载，通用解析可能找不到视频。
  • 海外站访问：能否下载取决于你本机网络和代理，工具本身不提供翻墙能力。
  • 直播：面向点播视频设计，不保证支持直播流。
  • 站点接口会变化，个别网站可能暂时失效，更新 yt-dlp 通常能恢复。
